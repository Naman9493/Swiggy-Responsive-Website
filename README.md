# Swiggy Responsive Landing Page

A responsive Swiggy-inspired homepage made with HTML5 and CSS3 only.

## Files
- `index.html` — page structure and content
- `style.css` — styling, layout, and responsive media queries
- `assets/` — locally included SVG illustrations for food, groceries, and service cards

## Run
Open `index.html` in any modern browser. No build tools or dependencies are required.

## Notes
- Layout adapts to desktop, tablet, and mobile widths.
- Search, sign-in, app-store, and navigation links are visual placeholders, as expected for a frontend clone.
- This is an educational fan-made frontend recreation, not an official Swiggy website.
